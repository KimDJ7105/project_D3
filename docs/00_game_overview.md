# 게임 개요

## 가제
미정 (추후 결정)

## 한 줄 소개
관계에 따라 반응이 달라지는 NPC/단체 시스템을 중심으로, 마을에서 준비하고 던전을 탐사하는 2D 탑뷰 칸 기반 턴제 전술 RPG.

## 핵심 축 (Core Pillars)
1. **관계 시스템** — NPC/단체와의 관계가 대사, 반응, 선택지, 그리고 던전 탐사 중 이벤트에 실질적인 영향을 준다.
2. **던전 탐사** — 마을(정비·준비) → 던전(탐사) 순환 구조. 던전을 고정형으로 할지, 로그라이크식 랜덤 생성으로 할지는 미정.

## 재미의 핵심 가설
관계가 던전 탐사에 "의외성"을 만든다.
- 예: 순조롭던 탐사가 관계가 나쁜 단체의 NPC와 마주쳐서 꼬인다.
- 예: 위기 상황에서 관계가 좋은 NPC가 난입해 도와준다.
- 플레이어 캐릭터는 던전에서 죽어도 마을로 돌아올 수 있지만, 동료 NPC는 진짜로 죽을 수 있다([[07_progression_death_system]]) — 이 비대칭이 관계에 실제 무게를 싣는다.

## 세계관 톤
던전 밖과 안의 **강한 대비**가 핵심. 다크소울류의 "세계 전체가 멸망해가는 암울함"은 지향점이 아님.
- **던전 밖(마을 등)**: 밝고 인간적인 세계. 사람들은 친절함.
- **던전 안**: 차갑고 인간을 믿을 수 없으며, 누가 죽어도 아무도 신경 쓰지 않는 세계.
- 던전은 초월적 존재가 만든 공간 + 고대 유적 + 외부 세계의 요소가 혼합된 곳. 사람들이 위험을 무릅쓰고 들어가는 기본 동기는 희귀 자원/재화(깊이 내려갈수록 더 큰 보상과 더 강한 몬스터). 자세한 내용은 [[08_world_and_factions]] 참고.

## 장르
2D 탑뷰, 칸(그리드) 기반 턴제 전투 + 런 기반 로그라이크·익스트랙션 던전 크롤러 + 관계/평판 시스템 RPG.

## 비주얼 레퍼런스
- 전투 화면: 건담 G 이터널 (칸 기반 탑뷰 전술 전투)
- 비주얼 스타일: 옥토패스 트래블러류의 2.5D(HD-2D)를 처음부터 지향. 캐릭터는 2D 도트 스프라이트를 유지하되 동적 그림자를 지게 하고, 일부 배경/외부 요소는 3D처럼 보이도록 연출한다. 엔진 자체는 결국 2D 기반이라 실제로는 전부 시각적 눈속임(트릭)에 의존 — 구현 방식은 [[04_tech_stack]] 참고.

## 플랫폼
- 기본: PC
- 웹 브라우저 vs 데스크톱 앱 여부는 미정 → [[04_tech_stack]] 참고, Godot의 동시 export 기능으로 결정을 늦출 수 있음

## 플레이어 캐릭터
커스터마이징 가능한 아바타. 지휘관형이 아니라 전투에 직접 참전한다.

## 개발 체제
1인 개발. 코딩 가능, 엔진 사용 경험은 없음(Godot 최초 사용).
