# 유파(스킬 계열) 시스템

세키로에서 영감을 받은 스킬 시스템. 전투 스킬을 "공용 스킬"과 "유파 전속 스킬"로 구분한다.

## 기본 구조
- **공용 스킬**: 특정 유파에 속하지 않고 누구나 배울 수 있는 스킬.
- **유파 스킬**: 대부분의 전투 스킬은 특정 유파에 소속되어 있음.

## 스킬 계열 축: 마법 유무 (결정됨 — 2026-08-09)
스킬(및 유파)은 크게 세 계열로 나뉜다.
1. **순수 물리/기술 계열** — 세키로류 무술/기술 중심.
2. **기존 마법류** — 이 세계에 전통적으로 존재해온 일반적인 마법.
3. **던전 기원 신마법류** — 던전의 초월적 기원([[08_world_and_factions]])에서 유래한 특수한 마법/이능. 일반 마법과 별개 계열로 취급.

세부(각 계열의 유파 목록, 계열 간 입문 조건 차이, 3번 계열이 스토리/세력과 어떻게 엮이는지)는 미정.

## 유파 규모 (결정됨 — 2026-08-10)
초기 출시 기준 **소규모(총 6~9개, 계열당 2~3개)** 로 시작. 1인 개발 콘텐츠 부담(유파당 저위/공용/고위 스킬 + 입문 조건 + 숙련도 곡선이 딸려옴)을 고려한 결정 — 관계 시스템처럼 콘텐츠 밀도가 높은 축과 부담이 겹치지 않도록 범위를 좁힘. 출시 후 콘텐츠로 유파를 추가하기 쉬운 구조로 설계하는 것을 전제로 함. 구체적인 유파 이름/컨셉 목록은 아직 미정.

## 유파 입문 및 숙련도
- 유저는 원하는 유파에 **입문**하여 소속될 수 있다.
- **중복 입문 가능**: 이론상 모든 유파에 동시에 가입할 수 있다.
- 일부 유파는 입문에 **조건**이 필요하다 (조건의 종류는 미정 — 퀘스트, 관계 수치, 아이템 등 검토 필요).
- 입문 후 **숙련도**를 쌓아 해당 유파의 상위 스킬을 해금한다 (숙련도 획득 방식은 미정 — 사용 빈도, 수련 행위, 퀘스트 보상 등 검토 필요).

## 스킬 슬롯
- 유저는 배운 스킬 중 **N개(기본안 4개, 확정 아님)** 를 선택해 스킬 슬롯에 설정한다.
- **던전 진입 후에는 슬롯 변경 불가.** 마을에서의 사전 준비가 곧 전략적 선택이 되며, [[02_dungeon_town_structure]] 의 마을-던전 루프와 직접 연결된다.
- **고위 기술 제한 (확인됨)**: 각 유파의 고위 기술은 다른 유파의 고위 기술과 동시에 슬롯에 설정할 수 없다. 즉 한 번의 던전 탐사에서 사용 가능한 고위 기술은 **하나의 유파** 소속으로 한정된다. 저위 스킬과 공용 스킬은 유파에 상관없이 자유롭게 섞어서 슬롯에 넣을 수 있으며, 이 제한은 오직 "고위 기술" 등급에만 적용된다.

## 스킬 구성 요소 및 스탯 스케일링 (결정됨 — 2026-08-09, 스탯 목록 확정 2026-08-10)
다크소울에서 영감을 받은 구조.

- 스킬은 크게 **데미지 / 사정거리 / 효과** 세 가지 요소로 구성된다.
- 스킬마다 영향을 받는 **스탯이 다르며**, 스탯별로 등급(스케일링)이 매겨진다.
  - 예시: 기술 A — 힘 A급, 기량 C급 / 기술 B — 힘 D급, 신앙 B급.
- **스탯 목록 확정**([[03_combat_system]] 참고): 체력 / 힘 / 기량 / 지능 / 신앙 / 신비 / 속도의 핵심 7개(2026-08-13 속도 추가).
  - 물리 계열 유파는 체력/힘/기량 위주로 스케일링.
  - 기존 마법류 유파는 지능/신앙 비중이 유파마다 다름 (예: 지능 위주 유파 vs 지능+신앙 혼합 유파).
  - 던전 기원 신마법류 유파는 신비 스탯을 상대적으로 더 자주 사용하는 경향 (전용은 아니며 유파별로 다름).
  - **속도**는 스킬 데미지 스케일링용이 아니라 초리어티 큐(턴 순서) 전용 스탯 — 위 스킬 스케일링 등급(힘 A급 등) 목록에는 해당 안 됨.

### 열린 질문 (미정)
- 스탯 8개로 확장할지 여부 (핵심 7개는 확정) — [[03_combat_system]].
- 스케일링 등급 체계 (예: S~E, A~E 등).
- 스탯 시스템이 [[01_relationship_system]] 의 개인 특성(Trait) 시스템과 별개인지, 접점이 있는지.

## 열린 질문 (미정)
- 유파의 구체적 이름/컨셉 목록 (규모는 소규모 6~9개로 결정됨).
- 유파별 입문 조건의 구체적 종류.
- 숙련도 획득 방식과 성장 곡선.
- 스킬 슬롯 개수 확정 (4개는 가안).
- "고위 기술"의 등급 기준 정의, 슬롯당 몇 개까지 장착 가능한지.
- 유파 시스템과 관계 시스템의 접점 가능성 (예: 유파 사범/동료 NPC와의 관계가 입문 조건이나 숙련도 획득에 영향을 주는지) — [[01_relationship_system]]
